# Challenge 08 - Counter

**Difficulty:** Easy

## Description

Create a React component called `Counter`.

The component allows users to increase, decrease,
and reset a numerical counter.

## Requirements

1. Create a functional component named `Counter`.
2. Use React's `useState` to manage the count.
3. The initial count must be 0.
4. Display the current count using this format:

   Count: [number]

5. Create three buttons:
   - Increment: increases the count by 1.
   - Decrement: decreases the count by 1.
   - Reset: sets the count back to 0.

## Expected Behavior

Initial state:
Count: 0

After clicking Increment:
Count: 1

After clicking Decrement:
Count: 0

After clicking Reset:
Count: 0

## Constraints

- Use TypeScript.
- Use functional components.
- Use React useState.
- Do not manipulate the DOM directly.
- Do not modify the provided tests.

## Concepts Practiced

- React useState
- State Management
- State Updates
- Event Handling
- Click Events
- Component Testing

## Completion Criteria

- [ ] Initial count is 0.
- [ ] Increment works correctly.
- [ ] Decrement works correctly.
- [ ] Multiple clicks work correctly.
- [ ] Reset works correctly.
- [ ] All tests pass.
